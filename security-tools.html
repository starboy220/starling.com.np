Security Tools.

Learn what common cybersecurity tools do, how their workflows work, and how to practice them safely in authorized labs.

This series exists because I kept noticing the same gap in beginner tutorials: plenty of pages tell you which flag to type, but very few explain what the tool is actually doing underneath, why the workflow looks the way it does, or how to practice legally and safely. Each guide below walks through the concept first, the workflow second, and a contained lab exercise last — always framed around systems you own or are explicitly authorized to test.

Six Tools, One Foundation

These six tools cover the core disciplines of hands-on security work: discovering what's on a network, inspecting how a web application talks to its users, watching raw traffic, validating whether a vulnerability is real, auditing password strength, and reviewing a web server's configuration. Learning them together builds a much more complete picture than learning any one in isolation.

Nmap

Nmap is a network discovery and security auditing tool used to identify hosts, open ports, services, and other characteristics of systems you are authorized to assess.

Open Guide →

Burp Suite

Burp Suite is a web application security testing platform. It lets authorized testers inspect, modify, and understand HTTP requests and responses while assessing an application.

Open Guide →

Wireshark

Wireshark is a network protocol analyzer used to capture and inspect network traffic. It is useful for troubleshooting, learning protocols, and investigating authorized security events.

Open Guide →

Metasploit

Metasploit is a security testing framework used by authorized professionals to validate vulnerabilities and understand how security controls respond in controlled environments.

Open Guide →

John the Ripper

John the Ripper is a password security auditing tool. In authorized environments, it can help assess whether password hashes are vulnerable to weak or guessable passwords.

Open Guide →

Nikto

Nikto is a web server scanner used to identify potentially risky files, outdated software, insecure configurations, and other issues on authorized web servers.

Suggested Learning Order

If you're starting from scratch, this order builds each tool on the concepts the last one taught you.

1

Nmap — start here to build a solid mental model of ports, protocols, and TCP/IP before anything else.

2

Wireshark — once you understand ports and protocols conceptually, watching real packets makes them concrete.

3

Burp Suite — move up the stack from raw packets to full HTTP requests and how web applications actually work.

4

Nikto — apply what you learned about HTTP to automated web-server configuration review.

5

John the Ripper — shift from network/web protocols to authentication and credential security.

6

Metasploit — bring it all together: networking, service identification, and vulnerability validation in one framework.

02 / ground_rules.txt

Ground Rules Across Every Guide

[+] Only test systems you own or have explicit written authorization to assess.

[+] Keep every lab on an isolated, host-only network — never bridged to production.

[+] Treat every scanner or tool finding as a lead to verify, not a confirmed result.

[+] Document what you did, what you found, and how you fixed it — the habit matters as much as the tool.
